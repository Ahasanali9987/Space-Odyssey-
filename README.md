# Space Odyssey 

A space-themed version of the classic Helicopter game.

Hold to rise, release to fall. Dodge planets, comets, asteroids and crystal spikes as you drift through deep space.

## How to Play

- **Hold** (mouse / finger / Space / ↑) → Spaceship goes up  
- **Release** → Spaceship falls down  
- Avoid everything  
- Distance = Score  

## Features

- Neon spaceship with engine thrust particles
- Dynamic space cave
- Obstacles with different speeds:
  - **Planets** (slow & heavy)
  - **Comets** (fast with trails)
  - **Asteroids** (medium speed)
  - **Crystal spikes** from top & bottom
- Particle effects
- Sound effects
- Live high score
- Mobile-friendly

## Controls

| Input              | Action     |
|--------------------|------------|
| Hold mouse / finger| Rise up    |
| Release            | Fall down  |
| Space / Arrow Up   | Rise up    |
